# 잉코데코 제품소개 이미지 전면 정리

## 목표
카탈로그 페이지를 그대로 캡처한 이미지를 모두 제거하고, 제품 사진·시공 사진·패턴 샘플·핵심 규격을 웹페이지에 맞게 각각 분리해 보여줍니다.

## 변경 내용
- 현재 제품소개 페이지의 이미지 15개를 전수 점검합니다.
- 카탈로그 지면이 보이는 흡음패널, 아웃도어, SPC 바닥재, SPC 월패널 이미지를 원본 PDF에서 다시 고해상도로 추출합니다.
- 제목, 설명문, 페이지 번호, 표가 함께 찍힌 지면 캡처는 사용하지 않습니다.
- 제품군별 이미지를 아래처럼 정리합니다.
  - 벽패널·흡음패널: 제품 표면, 루버 형태, 실제 벽·천장 적용 사진
  - 몰딩·부속: 개별 제품 형태와 마감 디테일
  - WPC 아웃도어: 외벽, 데크, 펜스, 화단의 실제 적용 사진
  - SPC 월패널: 모닝·그레이·나이트·컬러·클래식 스톤의 시공 사진과 패턴
  - SPC 바닥재: 실제 바닥 적용 사진과 우드 패턴 샘플
- 규격·성능·제품 코드는 이미지 속 작은 글씨 대신 페이지의 표와 설명으로 다시 작성합니다.
- 한 이미지에 여러 제품이 섞인 경우 핵심 제품별로 잘라 카드 또는 갤러리로 나눕니다.
- 이미지 비율과 색감을 통일해 제품 사진이 잘리지 않고 선명하게 보이도록 조정합니다.

## 기술 작업
- 업로드된 3개 잉코데코 제품 PDF에서 필요한 페이지를 고해상도로 렌더링하고, 제품/시공 영역만 정밀 크롭합니다.
- 새 이미지는 CDN 자산으로 교체하고 기존 코드의 이미지 연결을 갱신합니다.
- 제품소개 페이지 구조는 유지하되, 지면 캡처를 전제로 한 큰 이미지 영역은 제품 갤러리와 규격 목록으로 바꿉니다.
- 기존·2026 SS 카탈로그 내용은 하나의 제품소개 페이지 안에서 중복 없이 통합합니다.

## 확인
- 데스크톱과 모바일에서 전체 페이지를 확인합니다.
- 카탈로그 제목·페이지 번호·설명 박스가 이미지에 남지 않았는지 전수 확인합니다.
- 이미지 깨짐, 과도한 확대, 잘린 제품, 가로 넘침과 화면 오류를 점검합니다.
