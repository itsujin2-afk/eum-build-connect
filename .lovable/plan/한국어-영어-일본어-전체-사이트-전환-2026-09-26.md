# 한국어·영어·일본어 전체 사이트 전환

## 목표
- 메인, 회사소개, 6개 브랜드 소개, 모든 제품소개 페이지를 한국어·영어·일본어로 제공합니다.
- 상단 메뉴에서 `KO / EN / JP`를 선택하면 현재 보고 있는 페이지와 위치를 유지한 채 문구가 즉시 전환됩니다.
- 선택한 언어는 같은 브라우저에서 다음 방문에도 유지합니다.

## 구현 범위
1. 공통 언어 체계
   - 한국어를 기본 언어로 두고 영어·일본어 번역 데이터를 추가합니다.
   - 서버 첫 화면과 브라우저 화면이 다르지 않도록 안정적인 언어 상태를 구성합니다.
   - 문서 언어 정보도 선택 언어에 맞게 갱신합니다.

2. 상단 언어 메뉴
   - PC 상단 우측에 간결한 `KO / EN / JP` 선택 메뉴를 추가합니다.
   - 모바일 메뉴 안에도 동일한 언어 선택 항목을 넣습니다.
   - 기존 중앙 메뉴, 견적 상담 버튼, 오버레이 헤더의 가독성을 유지합니다.

3. 전체 문구 번역
   - 메인과 회사소개 전체 문구를 자연스러운 비즈니스 영어·일본어로 번역합니다.
   - 6개 브랜드 소개의 제목, 설명, 수치 라벨, 공정·제품·실적 문구를 번역합니다.
   - 환구석재·잉코데코·라이온킹·이센메이쥐·슈오펑의 제품소개 페이지 전체를 번역합니다.
   - 메뉴, 하단 정보, 문의 문구, 이미지 대체 설명과 접근성 문구도 함께 번역합니다.
   - 법인명, 대표자명, 등록번호, 주소, 모델명과 고유 브랜드명은 의미가 변하지 않도록 표기 규칙을 통일합니다.

4. 페이지별 검색·공유 정보
   - 각 페이지의 제목, 설명, 공유 제목과 설명을 언어별로 제공합니다.
   - 기존 페이지 주소는 그대로 유지해 현재 공개 링크가 깨지지 않게 합니다.

5. 확인
   - 한국어·영어·일본어 전환 후 주요 페이지와 제품 페이지를 PC·모바일에서 확인합니다.
   - 긴 영어·일본어 문장이 메뉴, 표, 카드, 버튼 밖으로 넘치지 않는지 점검합니다.
   - 깨진 이미지, 이동 오류, 화면 오류와 최종 빌드 상태를 확인합니다.

## 기술 세부사항
- 번역은 공통 언어 제공자와 페이지별 번역 데이터로 분리해 관리합니다.
- 브라우저 저장소는 화면이 뜬 뒤 안전하게 읽어 서버 렌더링과의 불일치를 방지합니다.
- 언어 전환 때문에 별도 복제 페이지나 중복 경로를 만들지 않고 기존 TanStack Router 구조를 유지합니다.
- 이미지에 포함된 기존 브랜드 로고 표기는 브랜드 고유 표기로 유지하며, 주변 설명과 대체 텍스트만 선택 언어에 맞춥니다.
