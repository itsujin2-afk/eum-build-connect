# 라이온킹 소개 페이지 확장

## 반영 내용
- 기존의 짧은 갤러리형 소개 화면을 자연스럽게 스크롤되는 브랜드 소개 페이지로 확장합니다.
- 카탈로그의 `VISION LIFE`와 `SPACE AESTHETICS` 철학을 읽기 쉬운 한국어로 정리합니다.
- 포산 기반의 생산·연구개발·판매 일체형 기업 소개, 첨단 설비, 국제 품질관리 내용을 반영합니다.
- 핵심 제품군인 풀바디 대리석 타일, 대리석 타일, 다이아몬드 글레이즈 타일, 내벽 타일을 소개합니다.
- 2025 포틀랜드 시리즈의 평면 6종과 몰드면 5종, 주문 제작 규격을 이미지 중심으로 보여줍니다.
- 카탈로그 전체 페이지 캡처 대신 타일 표면과 실제 공간 사진만 선별해 사용합니다.

## 화면 구성
1. 라이온킹 대표 이미지와 핵심 문구
2. 브랜드 철학과 기업 소개
3. 제품군과 품질·연구개발 강점
4. 포틀랜드 시리즈 표면 구성
5. 실제 공간 적용 이미지와 주문 제작 규격
6. 이음앤빌드 소개로 이동하는 연결 영역

## 확인
- 데스크톱과 모바일에서 이미지 비율, 글자 잘림, 가로 넘침을 확인합니다.
- 페이지 오류와 기존 메뉴 이동을 함께 점검합니다.
